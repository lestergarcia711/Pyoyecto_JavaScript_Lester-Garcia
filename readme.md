# 📌 Proyecto-JavaScript( Sistema de Parqueadero)
## 👤Por: Lester Garcia

## 📝Descripcion:
* El nombre en si del sistema es CampusParking, una aplicación web centralizada (SPA) creada para automatizar y optimizar la gestión de un parqueadero, ya que previamente todo el control de ingresos, salidas y registros se manejaba de forma manual. Desarrollado con HTML5, CSS3 y JavaScript, el sistema reemplaza las bitácoras físicas con un CRUD dinámico para tipos de vehículos y un control de flujos en tiempo real que almacena los datos en LocalStorage.

*  Toda esta lógica se integra en una interfaz moderna y minimalista en modo oscuro, con tonos pizarra y acentos en verde neón, que transforma un proceso tradicionalmente lento en una experiencia digital fluida y eficiente

## 🚀Ejecucion del proyecto:

1.Estructurar la carpeta: Agrupa tus archivos (index.html, tus carpetas de css y js) dentro de una sola carpeta principal en tu computadora.

2.Abrir en el editor: Abre Visual Studio Code (o el editor que uses) y selecciona "Abrir carpeta" para cargar todo el proyecto.

3.Iniciar el servidor local: Haz clic derecho sobre tu archivo HTML de inicio y selecciona "Open with Live Server" (para que la página se actualice automáticamente con cada cambio y no dé problemas de rutas).

4.Interactuar con la SPA: Prueba el inicio de sesión y navega por el menú para verificar que JavaScript cambie de sección correctamente sin recargar la página.

5.Validar los datos: Abre las herramientas de desarrollador del navegador (F12), ve a la pestaña Consola para revisar que no haya errores de código, y a la pestaña Aplicación > LocalStorage para comprobar que los datos se estén guardando con éxito.
